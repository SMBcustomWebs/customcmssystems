Body Content

The full-width content area below the header. Style it however you like using the editor's own toolbar.

 THE TOOLBAR IS LOADED FROM A FILE. custom_toolbar is a real field property (field.php:61) and resolve_dynamic_params() (field.php:194-232) is generic - it resolves ANY named property as a path relative to snippets/, not just opt_values. So dynamic='custom_toolbar' loads dropdowns/rich_sml_toolbar.inc and parses it, exactly the way dynamic='opt_values' loads a dropdown file. toolbar='custom' is required to reach that branch (field.php:717). That file's groups include Format, FontSize, TextColor and BGColor, so the editor CAN insert its own headings and inline styling here. For this block that is intended - the body row is the user's styling surface. The document outline stays under theme control because the section heading above is a separate text field whose element comes from ccs_img_2col_cntn_hdg_tag. These set DEFAULTS for the body area, not overrides of it. The classes land on the wrapping div, and font-size / weight / family / letter-spacing / line-height / colour are all inherited CSS properties, so the editor's own paragraphs pick them up. theme.css sets neither colour nor font-size on a bare p, so nothing intercepts the inheritance. Anything the user styles inside the editor is inline and therefore still wins - which is the right precedence for a block whose body is meant to be author-controlled. ">showhide

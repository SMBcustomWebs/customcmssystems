EVERY FIELD GETS A LABEL, not just a placeholder. This is not a preference. A placeholder disappears the moment someone types, so anyone who is interrupted loses the only clue about what the box was for; it is invisible to most screen readers as a name; and its grey-on-white default fails contrast in nearly every theme. Labels can be visually hidden if the design wants a clean look - the field below controls that - but the label ELEMENT is always emitted. WORDING IS EDITABLE because this block is not a restaurant. The source HTML hardcoded "Write your massage..." (sic) - which is both a typo and an assumption about the business. SPAM PROTECTION is deliberately not built yet. The section marked CAPTCHA SLOT in the theme is where it goes; reCAPTCHA is already loaded in kfunctions.php and its keys are set in config.php, so it is a small change when the approach is settled. =========================================================================

What each box is called

The label is what a screen reader announces and what appears above the box. The placeholder is the faint hint inside it.

Every box marked with a red star already has working wording in it. You do not have to type anything to put this form on a page. Change any of it you like – you just cannot leave one of them empty, because an unlabeled field is unusable to anyone on a screen reader and a button with no words is unusable to everyone.

The faint hints are genuinely optional and start out blank.

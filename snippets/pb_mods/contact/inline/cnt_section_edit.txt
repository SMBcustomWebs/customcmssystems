        TWO RULES THAT PRODUCE "Field not found", both learned on the
        transition banner:

        1. ONLY PAGE-LEVEL FIELDS MAY BE LISTED. inline_ex.php walks the PAGE
           fields list and dies on any name it cannot match. A field declared
           inside a cms:repeatable is not in that array. This block has no
           repeatables, so every name below is reachable - but the rule still
           governs anything added later.

        2. A NAME MUST BE A REGISTERED FIELD. Adding a field to an embed is not
           enough; Couch has to re-register the template before the name
           exists.

        A GROUP ONLY NESTS IF THE GROUP IS ALSO LISTED. inline_ex.php sets each
        field's group to its real group only when that group name is in the
        list too, and to nothing otherwise. That is why cnt_gen_grp and
        cnt_frm_grp appear in lists whose fields live inside them - drop the
        group and the popup renders the fields loose, with the group's own
        heading gone.

        QUOTING: link_text holds a whole button, so quotes inside it must be
        the other kind. Couch rejects a backslash-escaped quote in an attribute
        and stops at ATTRIB_NAME. plain uses single outer / double inner.
        toggle uses double outer / single inner, because its cms:if needs
        single quotes.

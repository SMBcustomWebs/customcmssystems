    THE SEND BUTTON. One window holding everything about it: the words, color,
    fill, shape, size, width, where it sits across the form, and the optional
    Font Awesome icon with its own color.

    THE CONTROL SITS ON THE THING IT CONTROLS. The button is the one part of
    the form that is a single pointable object, so unlike the appearance
    settings it needs no cluster of its own - it hangs off the button's own
    shrink-to-fit wrapper and travels with it when the author moves the button
    left, center or right.

    CUSTOMIZE SUBMIT BUTTON IS IN THIS WINDOW, first. Everything else here is
    inside the group that checkbox opens, so without it the window is fifteen
    controls JavaScript is hiding. Ticking it reveals them in place; unticking
    it puts the button back to a rounded primary one reading Submit, and the
    router ignores every stored value while it is off.

    NO DIMMED STATE. Every other switchable button in this block dims when
    what it opens is switched off. This one never can be: there is always a
    button on the page to edit, whether it is customized or not.

    THIS FILE IS EMBEDDED INSIDE THE cms:else BRANCH, so it is gone from the
    moment a message is sent until the page is loaded again. That is correct
    and not a gap - the button itself is gone too, and a control floating
    where its subject used to be is worse than no control.

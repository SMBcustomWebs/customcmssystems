Everything downstream that could reach a third party gates on those, so this has to run before any of it - hence line 2 rather than somewhere tidier. It emits no markup. It is wired up here rather than left dangling, because the moment someone pastes a tag into a field labelled "Header Scripts" they are entitled to assume it runs. It only prints once analytics consent is granted. That is the whole mechanism: a visitor who has not agreed does not receive a page with a tracker in it that is politely switched off - they receive a page that does not contain one. WHY ANALYTICS AND NOT MARKETING GOVERNS THIS SLOT. A head slot is where measurement tags go, and measurement is the analytics category. Anything genuinely marketing belongs in the footer slot below, which is gated on marketing consent. If a tag needs both, it needs the stricter of the two - put it in the footer. A tag that must run for the site to FUNCTION is not analytics and does not belong in either slot; it belongs in the theme, where consent does not apply because it is strictly necessary. THE PRECONNECT TO fonts.gstatic.com THAT USED TO SIT HERE IS GONE. A preconnect opens the TCP and TLS handshake to a host before anything asks for a file. It was there to make the Google font request faster - but the fonts are self-hosted now, so there is nothing to speed up, and leaving it would have kept opening a connection to Google on every page load for no reason at all. A connection nobody needs is still a connection a visitor did not agree to. google_fonts.htm keeps its name but no longer contacts Google; it links font CSS from assets/fonts/webfonts/.

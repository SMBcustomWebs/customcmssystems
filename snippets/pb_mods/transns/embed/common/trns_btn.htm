========================================================================= TRANSITION BANNER - CALL-TO-ACTION BUTTONS (4 slots) snippets/pb_mods/transns/embed/common/trns_btn.htm Rebuilt to mirror hero/embed/hero_cta.htm field for field. Read that file alongside this one; the shapes are deliberately identical so a fix in one transfers to the other. WHAT CHANGED AND WHY 1. NO SEPARATE "LINK TYPE" DROPDOWN. trns_frmt_c2a_opt is gone. The choice already lived in the color list - btn-colors.htm ends with "Link Only (not a button)=link" - so asking twice invited the two answers to disagree. Pick the color, and picking "Link Only" IS the choice to render a plain text link. That is hero's model. 2. NO PER-BUTTON TYPOGRAPHY. Text size, font family, weight, style and letter spacing are gone from every slot. Button size sets the text size, which is what Button Size is for. Hero never offered them either. 3. ICONS ON EVERY SLOT, LEFT OR RIGHT. Previously only slots 2 and 3 had an icon control and it was named inconsistently. Now all four use _cls/btn-icon-pos.htm, which emits the btn-icon base class together with the side modifier - theme.css writes every rule as .btn-icon.btn-icon-*, so the modifier alone matches nothing. The Font Awesome field appears only once a side is chosen - and both icon fields disappear entirely on an external URL, which supplies its own marker. 4. FILL IS A STEM, NOT A SUFFIX. _tok/btn-fill.htm emits btn or btn-outline and the router writes {fill}-{color}. The old button-fill.htm emitted '-outline' for the consumer to splice in, which is where btn--outline and btn-outlineprimary came from. CONDITIONAL SHAPE, per slot, exactly as hero does it: _is_link 0 when this slot is on AND color = link -> link color row _not_link 0 when this slot is on AND color != link -> button format row _is_custom 0 when this slot is on AND link = custom -> custom URL row _icon_pos_hide 0 when this slot is on AND link != custom -> icon side row _icon_show 0 when that holds AND a side is chosen -> icon class row Every func ANDs in trns_c2a_ct_opt so a hidden slot stays hidden. All four slots are generated from one template, so slot 3 cannot drift from slot 2. That mattered: the previous file had slot 3's func testing slot 2's field, which threw a ReferenceError and killed the admin's whole control-field wiring loop from that point on. ========================================================================= --- BUTTON 1 ------------------------------------------------------ 01

Call To Action 1

 01 01 01 ICON - AND NOT ON AN EXTERNAL URL. Choosing "Custom (External URL)" hides both icon fields, because an external link already gets one: the theme sets a right-side arrow-out-of-box marker and target="_blank" automatically, the same way utlbar/ubr_ctct does it. Leaving the icon controls visible would let the user pick a second icon that the marker then has to sit beside. So the rule is: the destination decides. Internal link, you choose an icon and a side. External link, the icon is chosen for you and says what it needs to say - this leaves the site. _icon_pos_hide gates the side dropdown. _icon_show gates the Font Awesome field and its help text, and additionally waits until a side has actually been picked. 01 01

Find icons at Font Awesome v6. Enter the full class, e.g. fa-solid fa-arrow-right

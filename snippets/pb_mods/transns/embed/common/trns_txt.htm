 " > show hide TYPED EFFECT. This used to carry its own static line, "Text Before Effect", plus a full set of typography controls to style it. That made a THIRD line of text appear after the user had already chosen "up to two lines" - and the third one styled itself independently, so matching it to the lines above was manual work that never quite matched. Gone. The typed words now append to the END of line 2, inside line 2's own div, so they inherit line 2's color, size, font, weight, style and letter spacing automatically. Line 2 IS the static part of the sentence now. That also removed the six typography fields that used to style the old static line - they had nothing left to style - and, in a second pass, the two overrides that used to recolor and re-weight the typed words. The animation IS the emphasis. Words that appear letter by letter on a loop already draw the eye; giving them a second color and weight on top of that fought with the line they belong to, and it was two more decisions for the user in exchange for nothing. So this row is now just the word list. The typed words inherit Line 2 completely, and the sentence reads as one sentence.

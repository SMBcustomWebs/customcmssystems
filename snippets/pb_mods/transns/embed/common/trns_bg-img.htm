SELF-CONTAINED: controller, func and slaves all at root in this file. INDEPENDENT OF THE COLOR. Previously the image group was gated on bg_clr_opt='img', which meant choosing an image ruled out choosing a color. Now a plain checkbox turns the image on, so a banner can carry color AND image at once - and the transparency dropdown below is what lets the color bleed through, which was the whole point. TRANSPARENCY uses dropdowns/img-transparency.htm, NOT bg-transparency.htm. The latter's first option is written 'No Transparancy' with no =value, so it emits its own label as the value and you get opacity: No Transparancy. img-transparency.htm emits real decimals (1.0 down to 0.0) and is what hero already uses. bg-transparency.htm is left untouched - it is outside this directory. =========================================================================

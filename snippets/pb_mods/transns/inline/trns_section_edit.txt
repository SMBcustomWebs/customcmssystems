        TWO RULES THAT PRODUCE "Field not found" IF BROKEN, both learned the
        hard way here:

        1. ONLY PAGE-LEVEL FIELDS MAY BE LISTED. inline_ex.php walks
           $PAGE->fields and dies on any name it cannot match. A field declared
           INSIDE a cms:repeatable is not in that array - it belongs to the
           repeatable's own row structure. So list the repeatable itself and
           never its children. Excluded for that reason:
               trns_txtbx_cstm_col_sz, trns_txtbx_cstm_col_val  (in trns_txtbx_cstm_sz_rpt)
               trns_txt_fx_txt_ln                               (in trns_txt_fx_rpt)
           Opening the repeatable in the popup still reaches every row and
           every field in it, so nothing is lost.

        2. A NAME MUST BE A REGISTERED FIELD. Adding a field to an embed is not
           enough - Couch has to re-register the template before the name
           exists, and until then the popup dies on it. That is what happens
           with a freshly added field like trns_min_h.

        The tag also takes skip='a|b' which suppresses the die for named
        fields. Deliberately not used: it would hide exactly the mistakes above
        instead of surfacing them.

        QUOTING: link_text holds a whole button, so quotes inside it must be the
        other kind. Couch rejects a backslash-escaped quote in an attribute and
        stops at ATTRIB_NAME. plain -> single outer / double inner. toggle ->
        double outer / single inner, because its cms:if needs single quotes.
    </cms:ignore>

=========================================================================== snippets/utils/google_fonts.htm THE NAME IS NOW HISTORICAL. This file no longer contacts Google. It kept its name only because head.htm and anything else embedding it would otherwise need changing too, and a rename is not worth a broken embed. WHAT CHANGED AND WHY. It used to end by emitting preconnect to fonts.googleapis.com preconnect to fonts.gstatic.com a stylesheet link to fonts.googleapis.com/css2 on every page load, for every visitor, before any consent existed. Loading a font that way transmits the visitor's IP address to a third party as a condition of reading the page, and a German court found in 2022 that doing it without consent is not permissible. Gating it behind the consent banner would technically comply and would also mean the site rendered in fallback fonts until someone clicked a button - visibly worse for everyone, including the people who would have said yes. Self-hosting removes the question rather than answering it. No third party, no consent needed, no first-paint penalty, and one less network round trip. THE SELECTION LOGIC BELOW IS UNTOUCHED. Which families the site wants is still decided exactly as before - custom overrides, then a theme preset, then the built-in default. Only the final step changed: instead of asking Google for those families, it links whichever of them are present locally. A MISSING FAMILY EMITS NOTHING AT ALL. Not a broken link, not a 404 - the file_exists check means the link is never written. That family then falls through to the system stack user.php already defines, so the page stays readable while the fonts are still being gathered. WHERE THE FILES GO assets/fonts/webfonts/montserrat/montserrat.css assets/fonts/webfonts/montserrat/*.woff2 Folder and css file both named as the family, lowercased, spaces to hyphens. See assets/fonts/webfonts/README.txt, and the header of any of the dropdowns/font-*.htm files, which generate their option lists by scanning that same folder. THE FOUR THEME PRESETS BYPASS THE DROPDOWNS and name families directly, so they are the set worth installing first. Between them they need eleven: Lato, Playfair Display, Dancing Script, Oswald, Montserrat, Cinzel, Open Sans, Merriweather, Roboto, Lora, Raleway. =========================================================================== Same eight-values-four-branches gap as user.php, and it has to be fixed in both or they disagree: user.php would ask for the default stack while this file requested nothing, so the families the CSS named would never be linked.

============================================================ SHOW / HIDE PASSWORD ------------------------------------------------------------ Adds a reveal toggle to every password field on the page. WHERE TO EMBED Once, anywhere inside the of a FRONT-END template that asks for a password. Never in the Couch admin - the admin has its own conventions and is not ours to restyle. NO MARKUP CHANGE NEEDED. It finds input[type="password"] at runtime and wraps each one, so it works on: cms:input type='password' (login.php) cms:input type='bound' ... (register.php, profile.php) The bound ones matter: extended_user_password is declared as type='dummy_password', whose _render() sets k_type='password' before delegating (extended-users.php), so it emits a real password input like any other. Nothing here has to know which of the two it is looking at, and a new password screen added later gets the toggle by embedding this one line. WHY A TOGGLE AT ALL A field nobody can read is a field people mistype, and the usual response to mistyping a password twice is to pick a shorter, worse one. Letting someone check what they typed is the accessibility fix and the security fix at the same time. DEFAULTS TO HIDDEN, always, and returns to hidden on submit so a revealed password is not left sitting on screen behind the next page. Nothing is stored, and the value is never touched - only the input's type attribute changes. ============================================================

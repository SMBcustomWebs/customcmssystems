"Global Default" was the first label here and it named nothing, so the only way to learn what it did was to pick it and look. What it actually does is defer to Default Website Brand Display, in Branding and Identity on globals.php - the site-wide choice between the logo and the site name in text. The label now says that. THE VALUES ARE UNTOUCHED. global, name, hoz and sqr are what every navbar and footer has stored; changing one would silently reset every block that holds it. Only the labels changed. Match the site-wide setting=global | Site name as text=name | Horizontal logo=hoz | Square logo=sqr

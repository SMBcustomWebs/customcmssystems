=========================================================================== snippets/dropdowns/_tok/space-gap.htm EMITS a bare step number on the site spacing scale, element range only. USE AS gap-{token} row-gap- column-gap- also valid behind ms- me- mt- mb- for nudging one item FOR the space between items that sit next to each other: buttons in a call-to-action row, chips, inline icons. ALWAYS EMITS SOMETHING no empty option, so no cms:if guard is needed. That is deliberate. A row of buttons with no gap class has its buttons touching, which always reads as a bug rather than a choice. "Small 1rem" leads as the default; a user who really wants them flush picks None, which emits gap-0 and says so out loud in the markup. STOPS AT "Wide" the full scale runs to 11, but the upper steps are section-scale. A gap that size between two buttons looks like a broken layout, not a design decision. Use _tok/space.htm for section padding where those steps are the point. For maintainers: the values are the same rem scale, 0 .25 .5 1 1.8 3 - the labels carry no units on purpose. "Touching" EMITS 0 AND NEEDS A != '' GUARD. PHP reads the string "0" as false, so a plain cms:if swallows it. Consume as cms:if field != '' gap-{field} VARIANT OF _tok/space.htm, per the house rule that a shared file is never edited to suit one block.

=========================================================================== snippets/dropdowns/_tok/color-link.htm EMITS a bare color token. USE AS link-{token} colors an anchor, with hover state text-{token} also valid for the gray numbers and the theme names, so the same choice can color a heading FOR anchors rendered as plain text links, not as buttons. When the row-level choice in _val/c2a-format.htm is "lnk", this is the color field; when it is "btn", use _tok/color-btn.htm instead. WHY THIS LIST every token is verified against theme.css as .link-{token}. The grays double as .text-{token}, which is why they carry the same labels as all-colors.htm and overlay-colors.htm. Keeping the labels identical across color files matters more than it looks: the user reads the same words everywhere and does not have to relearn the palette per field. NOT INCLUDED oxford .link-oxford exists but there is no .text-oxford or .bg-oxford, so offering it here would be the only place in the whole admin where that color appears.
